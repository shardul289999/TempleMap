Scoring methodology

Historical value is an editorial research score, not an official designation.

Each place is scored out of 100 using five signals so that an 8th-century protected monument is not ranked the same as a modern neighbourhood shrine.

30documented antiquity
25heritage / protection status
20architectural significance
15cultural & pilgrimage significance
10source confidence

Where the date of the present building is unknown, the map keeps the age blank rather than converting legends into factual construction dates.
